# devops-capstone-project

![Build Status](https://github.com/caitlynn-phillips/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)

A RESTful Customer Accounts microservice built with Flask, developed using Agile planning, Test-Driven Development, and CI/CD practices, and deployed to Kubernetes/OpenShift as part of the IBM DevOps and Software Engineering Professional Certificate capstone.
